# Moving file tabs
How the CSS-only slide works

Four equal-width labels share a row. The checked radio sets --selected from 0 to 3; both highlight layers translate by that number of tab widths. CSS also shows the matching panel.

.tab-strip { display: grid; grid-template-columns: repeat(4, 1fr); }
.moving-fill, .moving-ink {
  width: calc((100% - 8px) / 4);
  transform: translateX(calc(var(--selected) * 100%));
  transition: transform 180ms cubic-bezier(.2, 0, 0, 1);
}
.demo > input:nth-of-type(2):checked ~ .tab-strip { --selected: 1; }
/* Similarly: third input = 2, fourth input = 3. */

JavaScript needed? No for this demo. If each tab must have a different natural width and the sliding fill must fit that width exactly, measuring the selected tab with JavaScript is the straightforward approach.
