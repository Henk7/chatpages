What the numbers mean

  • API tokens / month: spend the whole monthly credit on the chosen model with your selected input/output split.
  • API tokens / €: estimated API tokens divided by that plan’s monthly subscription price in euros.
  • Chat and coding: plans also include separate usage allowances. Providers generally don’t disclose a fixed monthly token quantity for them.
Tokens = credit ÷ ((input share × input price) + (output share × output price)) × 1,000,000.
Tokens / € = tokens ÷ monthly price. API prices and credits are both in USD, so no exchange rate is needed.

What can change the result

  • Model quality, features and availability differ. A token from one model isn’t necessarily equivalent to another.
  • Long-context surcharges, caching, reasoning tokens, tools, media, taxes or other fees can change real usage. OpenAI long-context rates may apply above 272k input tokens.
  • Google Cloud credits can also be used on other eligible services; Google Flow credits are a different benefit. Credits need activation and eligible accounts. Some Google billing accounts require prepayment.
  • OpenAI and Claude credits expire at the end of the billing cycle; Google says its Cloud credits expire one year after grant. Check current terms.
